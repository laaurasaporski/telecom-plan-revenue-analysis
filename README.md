Neste projeto, atuei como analista de dados em um cenário simulado para a empresa de telecomunicações Megaline. A empresa oferece dois planos pré-pagos: Surf e Ultimate. O objetivo era identificar qual dos planos gera mais receita, a fim de auxiliar na otimização do orçamento de publicidade.

Para isso, realizei uma análise preliminar com base em uma amostra de 500 clientes. O conjunto de dados incluía informações como perfil dos clientes, localização, plano contratado e o número de chamadas e mensagens realizadas ao longo de 2018. Meu objetivo foi analisar o comportamento dos clientes e determinar qual plano pré-pago gera, em média, maior receita.

Ao longo do projeto, segui diretrizes analíticas específicas para avaliar aspectos relevantes do comportamento dos clientes. Para identificar qual plano é mais lucrativo em termos médios, utilizei testes estatísticos como parte da análise.
